# ERP Automation System

이 프로젝트는 회사에서 자주 하는 결재 업무를 더 편하게 만들기 위한 데모 프로젝트입니다.

결재서를 작성하고, 내용을 정리하고, 빠뜨린 항목이 없는지 확인하며, 결재자를 지정하고, 임시 저장하는 과정을 실제처럼 따라 해볼 수 있습니다. 단순히 화면만 보여주는 것이 아니라, 업무 흐름을 이해하기 쉽게 만들기 위한 예시입니다.

## 이 프로젝트는 무엇을 보여주나요?

이 프로젝트는 실제 ERP 시스템을 그대로 연결한 서비스가 아니라, 비슷한 업무 흐름을 로컬 환경에서 체험할 수 있도록 만든 데모입니다.

다음과 같은 기능을 경험할 수 있습니다.

- 결재서 작성
- AI가 내용을 간단하게 정리해 주는 기능
- 필수 정보가 빠지지 않았는지 확인하는 검증 기능
- 결재자 지정
- 임시 저장
- 최종 상신은 담당자가 직접 처리

즉, 이 프로젝트는 "완성된 ERP 연동 서비스"가 아니라, "ERP 업무를 자동화하는 아이디어를 보여주는 예시"라고 이해하면 됩니다.

## 어떤 점이 편리한가요?

- 결재 내용을 빠르게 입력할 수 있습니다.
- 중요한 항목을 놓치지 않도록 안내해 줍니다.
- AI가 문서를 간단하게 정리해 줍니다.
- 결재 절차를 한 번에 이해하기 쉽습니다.
- 실제 ERP 연결 없이도 흐름을 테스트해 볼 수 있습니다.

## 기술 구성

이 프로젝트는 다음 기술을 사용합니다.

- Next.js: 웹 화면 제작
- Node.js + Express: 로컬 API 서버
- Playwright: 브라우저 자동화 검증
- pnpm: 패키지 관리
- mock data + validation: 데모용 데이터와 검증 로직

## API 관련 안내

실제 ERP 회사 시스템은 대부분 외부에 공개된 API를 제공하지 않습니다. 그래서 이 프로젝트는 외부 실서버와 연결하지 않고, 로컬에서 동작하는 mock API를 사용합니다.

현재 구조는 다음과 같습니다.

- 실제 ERP API 대신 mock API 사용
- 브라우저 자동화로 화면 흐름 확인
- 최종 상신은 사용자가 직접 처리

즉, 이 프로젝트는 실제 업무 시스템과 100% 동일한 연동을 목표로 하기보다, 업무 자동화 아이디어와 흐름을 보여주는 데모에 더 초점을 맞추고 있습니다.

## 실행 방법

아래 가이드를 참고하면 상황에 맞는 실행 방식으로 바로 시작할 수 있습니다.

- 전체 실행 가이드: [docs/run-guide.md](docs/run-guide.md)
- 로컬 스토리북 패턴 페이지: http://localhost:3000/stories
- GitHub Pages 스토리 목록: https://leeseungje.github.io/stories
- 실행 요약 링크: [실행 가이드 바로 보기](docs/run-guide.md)

### 1) 저장소로 이동

```bash
cd D:\erp_system
```

### 2) 의존성 설치

```bash
pnpm install
```

### 3) 전체 프로젝트 실행

```bash
pnpm dev
```

### 4) 웹만 실행

```bash
pnpm --dir apps/web dev
```

### 5) API만 실행

```bash
pnpm --dir apps/api dev
```

### 6) 접속 주소

- 웹 화면: http://localhost:3000
- mock API: http://localhost:4000
- 패턴 페이지: http://localhost:3000/stories

## 자동화 검증 실행

다음 명령으로 브라우저 자동화 검증을 실행할 수 있습니다.

```bash
cd D:\erp_system
$env:ERP_WEB_URL='http://localhost:3000'
pnpm --dir apps/automation smoke
```

이 명령은 화면에서 핵심 흐름이 정상적으로 동작하는지 자동으로 확인하는 역할을 합니다.

## 주의사항

- 최종 상신 버튼은 담당자가 직접 눌러야 합니다.
- 실제 ERP API가 공개되어 있지 않아 마지막 단계는 자동화하지 않았습니다.
- 이 프로젝트는 데모용이며, mock 데이터와 자동화 검증을 활용합니다.

## 한 줄 정리

이 프로젝트는 실제 ERP 연동 대신, ERP 결재 업무의 자동화 아이디어와 흐름을 쉽게 보여주는 데모 프로젝트입니다.
